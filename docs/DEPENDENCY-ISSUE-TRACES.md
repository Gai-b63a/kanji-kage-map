## 再現と検証範囲

公開済みの独立DBだけで実行できます。

```powershell
python tools/report_dependency_issues.py path/to/kanji-kage-map-v0.1.sqlite3 --output dependency-issue-traces.json
```

この処理は、既存監査が問題ありとした候補の経路を再取得し、問題行の文字列を保存済み原KAGEと照合します。候補の問題理由と到達した局所所見の集合が一致すること、DB内の全局所所見が少なくとも一つの候補から到達できることも確認します。既存監査で完全とされた候補を改めて全閉包検査する処理ではありません。全閉包監査は [GlyphWiki監査](GLYPHWIKI-AUDIT.md)、別の構文所見は [静的検査](SYNTAX-AUDIT.md)を参照してください。

全所見の原データは無改変で保持し、レビュー状態は未レビューのままです。本記録は字形対応の確定や修正データではなく、利用者が問題の影響元を追跡するための資料です。
