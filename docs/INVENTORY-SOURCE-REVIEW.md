# 台帳解析課題の原本レビュー

2026-11-04、解析課題キュー61識別子・160指摘について、固定原本と採用Unicode 18.0.0の属性を照合しました。これは原本の記述と分類のレビューです。KAGEとの字形一致を確認したものではなく、確認済み対応は引き続き0件です。

| 判断 | 識別子数 | 扱い |
| --- | ---: | --- |
| 割当済みUnicode文字だが採用漢字・部首集合の外 | 49 | `other_unicode` の部品として保持 |
| 一つの完全なIDSにならない原記述 | 11 | 項数の課題を保持し、修正を推測しない |
| IDS内の空白 | 1 | 原文を保持。空白を除いた構造は一つの完全な式 |

49件にはラテン文字、仮名、ハングル、八卦、U+3007 IDEOGRAPHIC NUMBER ZERO、蘇州数字を含みます。「集合の外」は本プロジェクトで採用した母集団に関する分類であり、文字の文化的な分類や字形の不正を意味しません。U+3007なども漢字集合へ黙って算入せず、既存の識別子を維持します。

原記述の構造課題11件は、PUA `E945, EA13, EDE1, F0E8, F11E, F164, F4FC, F579, F825, F8CC, F8CD`（いずれもBabelStone Han PUA 1.473）です。例えばF164の `⿰氵丰月` は二項演算子に対して葉が三つ、F579の `尸ソ` は演算子なしで二つの葉があります。期待する字形や演算子の補完は決めていません。

空白の対象E4FAは `⿱口⿰⿰丶丶 口` です。列挙時に空白を飛ばしても葉の識別子を失いませんが、原文は変更しません。

## 証拠と検証範囲

[inventory-source-review.json](inventory-source-review.json) は全61件の判断、次の調査事項、160件の原本位置・版・URL・SHA-256、非漢字集合の葉のUnicodeブロック、式の根数／不足する子の数を記録します。レビュー者はCodexであり、人による字形目視確認を意味しません。

TXTは指定行の元IDとIDS欄、HTMLは指定行から始まる対象表の元IDとIDSセルを照合しました。近隣行や説明文に同じ文字があるだけでは受理しません。HTMLの元IDに付く `*` は注記として扱います。TXTとHTMLの記述一致は同じ提供元の二形式の整合性であり、独立した典拠による正しさの証明ではありません。

演算子の項数は固定PropListの `IDS_Unary_Operator`、`IDS_Binary_Operator`、`IDS_Trinary_Operator` から構成し、既存パーサーの項数表と完全一致することを確認しました。原本キューの該当行を意図的に一行ずらした入力では、証拠不一致として失敗し、レビュー結果を書き出さないことも確認しました。

```powershell
python tools/review_inventory_sources.py
```

この処理は配布済みDB・対応状態・元の課題キューを変更しません。`source_review_status: source_audit_complete` と `glyph_review_status: unreviewed` を分けています。IDSの訂正は提供元の明示的な訂正、字形判断は対象版の字形資料と版付きKAGEの比較を必要とします。
