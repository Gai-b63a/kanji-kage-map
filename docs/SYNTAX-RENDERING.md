## 再現

既存package-lockでエンジンを用意し、次を実行する。0.7.0以外は拒否する。所見一覧のハッシュ、全554件の所属、所見の発生元・理由が変わる場合も失敗する。

```text
python tools/audit_syntax_rendering.py DATASET.sqlite3 --output data/generated/review/syntax-rendering
```

出力には無改変bundleの入力JSON、描画結果、圧縮全件記録、要約を保存する。コードは既存の通常レンダラーを使用し、依存問題の拒否を緩和しない。この検証と結果はpreview.2公開後の追加で、同版ZIPには含まれない。
