# 固定PUA表の原典リンク

2026-11-04。PUA表1.473の全6,030識別子について、原典欄と出典ID欄のハイパーリンクを原HTMLから抽出した。4,286識別子に計6,038リンクがあり、残る1,744識別子にはこの2欄のリンクがない。リンクなしを「出典なし」とは扱わない。書名や資料位置だけが書かれた行もある。

[全件JSONL.gz](pua-source-links.jsonl.gz)と[要約](pua-source-links-summary.json)には版付き識別子、原表ハッシュ、列の区分、URL、リンクの表示文字列、原HTML行番号を保存する。台帳とのID集合一致を検査し、重複・欠落を拒否する。表示上の文字実体 `&amp;` はURLの `&` に戻す。原表全体の説明文やフォントは再配布しない。

これは原典を調べるための索引で、リンク先の取得、画像の版確認、字形一致を終えたという記録ではない。全行を `links_unverified` または `no_source_hyperlink` として扱い、mapping候補・確認状態は変更しない。

## フォントにない6字の調査経路

- E87B・E87C：国家図書館の《淵鑑類函》巻229、16aへの同じリンク。
- E87D：Harvardの《潛確居類書》巻96、25bへのリンク。
- E87F：Wikimedia Commonsの《外臺祕要方》巻32、13aへのリンク。
- F55A・F55B：原典欄・出典ID欄とも空欄で、原典リンクもない。字形の根拠を別途探す必要がある。

正確なURLは要約の `missing_font_entities` に保存した。フォント欠落をIDSから作図して埋めることはしない。

## 版差の再確認

[公式ページ](https://www.babelstone.co.uk/Fonts/PUA.html)は1.473を表示する。公式TTFをCache-Control/Pragmaのno-cache指定で再取得したが、5,106,372バイト、SHA-256 `92e7155bd28f5570449f4dc71e9bb6fa919f67ef0120d4f83b58c61bed3ed4dc` で、以前取得し内部版1.472と確認した実体と同一だった。[再取得記録](pua-font-recheck.json)。そのため版差の解消とはしない。no-cache指定が途中の配信設備で必ず尊重されたとまでは断定しない。

再抽出は `python tools/extract_pua_source_links.py`。リンク列・文字実体・入れ子ラベル・リンクのない行の保持をテストする。この索引はpreview.2公開後の追加。
