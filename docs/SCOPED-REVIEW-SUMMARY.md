# 典拠・評価基準を保持したレビュー集計

`tools/summarize_reviews.py` は、独立DBに埋め込まれた判断履歴を検証し、最新の撤回されていない記録だけを集計する。mappingの確認状態や候補選択は変更しない。

```text
python tools/summarize_reviews.py DATASET.sqlite3 --output summary.json
```

出力には入力DB・GlyphWiki snapshot・判断履歴のSHA-256を記録する。全履歴の形式と訂正／撤回関係、各判断と候補の版の一致を検査する。現在のレコード数、撤回数、評価範囲・基準・判断別の件数、AI／人間の区分を分ける。典拠の版・ハッシュ・所在、地域典拠ID、字形名と版を各行に保持する。

同じ識別子・snapshot・典拠・基準に対して複数の候補がequivalentと記録されている場合は、候補の一覧を明示する。一つを自動選択せず、異なる地域典拠の結果を相殺しない。履歴契約が同一subjectの無関係な並列判断を拒否するため、独立した複数判断者間の合意形成や優先順位付けはこの集計の対象外。

[ローカル訂正版の集計結果](scoped-review-summary.json)では、全109,556識別子のうち2識別子に計3件の有効な範囲限定記録がある。内訳は構造一致1、構造差1、判断材料不足1で、いずれもAI判断。撤回は0件。同一典拠に複数の一致候補を持つケースは0件。残る109,554識別子には、この判断履歴形式による有効な記録がない。これは他の特徴観察・静的監査が一切ないという意味ではない。

「2識別子に記録がある」を「2識別子が一致確認済み」とは扱わない。レコードの集計は全件レビュー完了を意味しない。撤回と複数候補・典拠分離の回帰テストを追加し、全74テスト通過。今回の集計機能は、既に実行中のpreview.2公開ジョブには含まれない後続変更。
