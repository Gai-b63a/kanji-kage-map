## 候補リンクと依存検査

955,185候補リンクのうち、既存の参照・命令タグ監査で課題なしは955,178、課題ありは7です。この割合はリンクを分母にしています。同じ字形が異なる識別子の候補に現れた場合、リンクとして別に数えます。

複数候補を持つ識別子は100,972件です。「課題なしの候補が一つでもある識別子」は105,657件で、課題ありの候補を併せ持つ7識別子も含みます。これらを単一の採用字形へ絞ってはいません。

この集計の依存状態は、全座標・KAGE意味論・描画・字形一致を保証しません。追加の静的検査で所見のある418字形とは検査範囲と母数が異なります。[静的検査の範囲](SYNTAX-AUDIT.md)

## 再生成と検証

```powershell
python tools/report_coverage.py path/to/kanji-kage-map-v0.1.sqlite3 --output docs/coverage.json
```

台帳と対応表のID集合が等しいこと、全レコードのsnapshot、候補有無と探索状態の整合性を確認して集計します。未知の状態、重複ID、空の母集団は失敗として扱います。候補リンクが0件の集合について、依存成功割合は100%や0%ではなく `null`（分母なし）です。

現在の未レビュー契約専用の集計です。確認済み判断が導入された場合は黙って0件と集計せず、証拠を検証できる集計への更新を要求して停止します。既存の公開DBや対応判定は変更しません。
