# 番号付き部品とPUAの原資料上の関係

IDS 2025-06-27の番号付き部品121件を、採用PUA表1.473と全件比較しました。原IDSの72–73行は、定義の括弧内にBabelStone Han PUAフォントの対応するPUA文字を示すと説明しています。ただしフォントの版は指定されていません。この原資料の明示的な参照を記録し、符号位置だけから対象版での同一字形を認定しないようにします。

| 原資料間の比較 | 件数 |
| --- | ---: |
| 定義が明示するPUA符号位置を採用表で発見 | 121 |
| IDS文字列が同じ | 44 |
| 番号定義は未知部品「？」、PUA表は空欄 | 66 |
| その他のIDS記述差 | 11 |

44+66+11が121件の内訳です。文字列一致の44件も字形確認済みではありません。未知部品と空欄の66件を同じ形と扱うこともありません。

その他の差がある部品番号は `{9}, {13}, {20}, {42}, {43}, {48}, {58}, {67}, {100}, {110}, {120}` です。例えば `{9}` では㇖／乛、`{13}` では⺂／乛という構成要素表記の違いがあり、`{100}` は番号定義の「？」に対してPUA表には `㇯之丶` の記述があります。記述の差は字形の相違の証明ではなく、同一視する前に確認すべき証拠です。

全件の版付き元ID、明示されたPUA符号位置、比較対象の版付きID、双方の資料位置・URL・SHA-256、二つのIDS文字列と比較結果は [numbered-component-source-review.json](numbered-component-source-review.json) に保存しました。元IDSの説明文やPUA表の説明文を複製した対照表ではありません。

```powershell
python tools/review_numbered_components.py
```

固定原本をハッシュ照合したうえで番号定義を再抽出します。出典記述にないPUA参照の補完、IDSからのKAGE変換、PUA候補を番号部品の候補へ自動転記することは行いません。既存の候補状態は変更していません。

次に必要なのは、IDS原本が想定するPUAフォント版の特定、対象PUA版までの符号位置・字形の継続性の根拠、および独立した部品字形との比較です。完成字形内の部品に似ているだけでは一致にしません。現時点で番号付き部品の確認済み字形対応は0件です。
